No master passwords, recovery answers, browsing URLs, or personal data are ever sent to, synced with, or stored in any cloud, external server, or third-party database. 3 Browser-Level Scope vs. Operating System Security

ChromeLock enforces security at the Google Chrome application layer across windows, tabs, and URL navigations. It is NOT an operating system replacement (such as Windows Hello, BitLocker disk encryption, or OS login accounts). It cannot prevent an operating system administrator or local software with task management privileges from terminating the Google Chrome process or removing extension directories from the computer's hard drive.

5 Recovery Question Integrity

The optional recovery question allows you to reset your password locally. For user convenience, security answers are evaluated in a case-insensitive manner (e.g., lowercase, uppercase, and trimmed whitespace are treated equally). However, answers are securely salted and hashed with PBKDF2 and cannot be inspected in plaintext. Keep your recovery answer confidential.
